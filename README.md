# WordPress Site

This repository contains the full WordPress installation, including the custom **Group Leader Dashboard** plugin (`wp-content/plugins/gl-dashboard`).

## What's NOT in this repo

| Excluded | Why |
|---|---|
| `wp-config.php` | Contains live DB credentials and secret keys — never commit |
| `wp-content/uploads/` | ~846 MB of media — store separately (S3, backup service, etc.) |
| `bv_connector_*.php` / `malcare-waf.php` | Auto-generated by MalCare on every deploy |

## Setup on a new server

1. Clone the repo into your web root.
2. Copy `wp-config-sample.php` → `wp-config.php` and fill in all `REPLACE_WITH_…` values.
3. Import the database (`mysqldump` from production, or a WP migration plugin).
4. Restore `wp-content/uploads/` from backup.
5. Install Redis and enable the Redis Object Cache plugin.
6. Add the server-side cron (replaces WP-Cron):
   ```
   */5 * * * * www-data php /var/www/html/wp-cron.php > /dev/null 2>&1
   ```

## Custom plugin: Group Leader Dashboard

Located at `wp-content/plugins/gl-dashboard/`. See that folder for full details.

Key features:
- LearnDash group leader portal (course progress, analytics, user management)
- Paginated REST API (50 users/page) — handles large groups without memory errors
- 10-minute transient cache + Redis object cache for fast responses
- 5-minute cron cache warmer — group leaders always hit a warm cache
- WooCommerce integration — automatic access grant on order completion
- Annual subscription with 7-day and 1-day expiry email warnings
